# FlowKeyboard · 传送带旋转输入法

An offline Android input method with four continuously looping key lanes. Tap a key anywhere, tap it at the fixed target line, or drag and fling an individual lane. Switch between a horizontal conveyor and a vertical waterfall, English and pinyin, QWERTY and alphabetical order. Cruise speed, direction, sound and haptics persist across launches.

## Run

Requires JDK 17, Gradle 9.2.1, Android SDK 36 and build tools 36.0.0. The configured local SDK is `/opt/android-sdk`; AAPT2 is launched through `/opt/aapt2`.

```sh
./gradlew testDebugUnitTest --info
./gradlew assembleDebug
./gradlew assembleRelease
```

Install `app/build/outputs/apk/debug/app-debug.apk`, open FlowKeyboard, choose **Enable FlowKeyboard**, then **Select keyboard**. The built-in EditText sandbox works before enabling the input method. Release output is unsigned until a production signing configuration is supplied.

## Toolchain compatibility

SDK 36, AGP 9.0.1, Kotlin/Compose compiler 2.2.10, KSP 2.2.10-2.0.2, Room 2.8.5, DataStore 1.2.1, Koin 4.2.2, Lifecycle 2.10.0 and Activity Compose 1.13.0 are configured in the version catalog.

The catalog uses Compose BOM **2026.01.00**. The originally requested **2026.09.00** selects Compose 1.12.1 artifacts whose AAR metadata requires **compile SDK 37 and AGP 9.1.0**. BOM 2026.01.00 preserves the required SDK 36 / AGP 9.0.1 toolchain without disabling metadata validation. `android.disallowKotlinSourceSets=false` supports generated-source registration by the requested KSP version with AGP's built-in Kotlin.

R8 full mode and resource shrinking run in the release variant. Debug assembly checks compilation and packaging; release assembly checks the shrinker.

## Architecture and behavior

Compose screens consume immutable state and send actions to ViewModels. Koin supplies Room, DataStore, repositories and per-keyboard engines. The IME owns its lifecycle, saved state and ViewModel store; its composition and frame loop stop with the input view. The same keyboard content and action handler power the application sandbox.

Pinyin letters appear as an editor composing span and trigger Room prefix/initial searches. Tap a candidate or press Space to commit it; Enter commits then respects the editor action. Unmatched compositions commit their original pinyin. Backspace edits composition before surrounding text, and handles selected text and UTF-16 surrogate pairs. Each candidate selection atomically increases its stored frequency and reorders subsequent searches.

The database is transactionally seeded with **1,000 Chinese entries** on creation. No network permission is requested. Learning stores selected dictionary IDs and aggregate session counts; typed text is never saved. Password editors and editors requesting no personalized learning use English and skip learning/statistics. WPM is committed code points divided by five, scaled by session duration. Saved statistics update when a session ends.

Physics functions are independent of Android: cyclic coordinates, target hit detection, bounded fling velocity and time-based damping. Animation uses Compose frame timestamps; fling motion combines with cruise motion and wraps continuously. Screen-reader custom actions type the key currently aligned with each lane's target.

## Tests and assets

The test suites cover cyclic math, bounded pinyin composition and syllables, InputConnection editing/actions, real in-memory SQLite Room queries and self-learning, preference persistence and concurrent updates, layouts and ViewModel composition/privacy. Room tests use AndroidX's bundled SQLite driver so they also run on Linux ARM64 hosts where Robolectric's framework SQLite native runtime is unavailable.

`app/schemas` contains the exported Room schema. `tools/generate_assets.py` reproducibly creates the dictionary and original WAV mechanical clicks using `pypinyin==0.55.0` and `wordfreq==3.1.1`; these tools are not runtime dependencies. Dictionary vocabulary is derived from wordfreq by Robyn Speer, with curated additions and generated pinyin. The dictionary is CC BY-SA 4.0; source attributions and licenses are bundled under `app/src/main/assets/licenses`. Sound effects are generated by the included script.
